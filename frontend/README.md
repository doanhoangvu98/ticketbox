# TicketBox Web

React 19 · Vite · TypeScript · Tailwind v4 · TanStack Query · axios · MSW · react-toastify · VietQR · Remix Icon.
Tài liệu đầy đủ: [`../docs/FRONTEND.md`](../docs/FRONTEND.md).

```bash
npm install
npm run dev      # http://localhost:8000
```

- `.env.local`: `VITE_USE_MOCK=true` chạy hoàn toàn bằng mock (không cần backend). `VITE_MOCK_EXCLUDE=auth,events` để nối dần backend thật.
- Tài khoản demo (mật khẩu `123456`): `customer@`, `organizer@`, `staff@`, `admin@ticketbox.vn`, hoặc bấm nút **MOCK** góc trái dưới.
