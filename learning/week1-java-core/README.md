# week1-java-core (bài học)

Code học tập cho **bước 1 (Java Core)** và **bước 1B (đa luồng)**. Project Maven độc lập, chỉ dùng JDK 21.
Sản phẩm (`backend/`) **không** phụ thuộc project này.

```bash
mvn test        # toàn bộ test, gồm ConcurrencyTest (10.000 virtual thread)
mvn exec:java   # demo console
```
